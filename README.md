# Moodle™ container image by Oksigenia

> **Work in progress.** No images are published yet. This repository will hold the source, the build pipeline and the documentation of `oksigenia/moodle`, a maintained, open-source container image of the Moodle™ LMS software.

**Planned:**
- Moodle™ 4.5 LTS, 5.2 and 5.3 LTS, rebuilt every week.
- amd64 and arm64.
- Signed images, with SBOM and provenance.
- A tested migration path from `bitnami/moodle` and `bitnamilegacy/moodle`.
